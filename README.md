# JARVIS - Voice Assistant

A Python-based voice assistant inspired by Tony Stark's JARVIS from Iron Man.

## Features

- Voice recognition and text-to-speech
- Web browsing commands (Google, Facebook, YouTube, LinkedIn)
- Music playback from custom library
- News headlines fetching
- Voice activation with "Jarvis" wake word

## Requirements

- Python 3.x
- speech_recognition
- pyttsx3
- requests

## Installation

1. Clone the repository
2. Install required packages:
   ```
   pip install speech_recognition pyttsx3 requests
   ```
3. Run the application:
   ```
   python main.py
   ```

## Usage

1. Say "Jarvis" to activate
2. Give commands like:
   - "Open Google"
   - "Open YouTube"
   - "Play [song name]"
   - "News"
